# Code of conduct

Tentmaker is a small project, and these rules keep it a good place to work.

- Be kind and assume good faith. Criticize code and ideas, not people.
- Stay on topic. Issues and pull requests are for Tentmaker.
- No harassment, insults, threats or spam, here or toward anyone you met here.
- Don't post anyone's private information, including your own tokens and host names.

The maintainer may edit or remove comments, close threads, and block anyone who breaks these
rules. To report a problem privately, use GitHub's **Report content** on the comment or the
user, or open a private report from the repo's **Security** tab if it involves a vulnerability.
